# AIまなびば 🌸

AI活用学習ハブ。Microsoft Teamsのチャネル上部にタブとして置いて使うための、1ファイル完結のウェブサイトです。全員に共通の同じページが表示されます(ログインや個人ごとの保存はありません)。

## コンテンツの種類

| タグ | 内容 | ボタン |
| --- | --- | --- |
| 教務×AI 動画 | 教務に使えるAI活用動画 | 動画を見る + 実践報告フォーム(Forms) |
| 授業×AI 動画 | 授業に使えるAI活用動画 | 動画を見る + 実践報告フォーム(Forms) |
| iportal記事 | 社内ブログ(iportal)の記事 | 記事を読む |
| note記事 | note記事 | 記事を読む |

そのほかの機能:

- タグ(カテゴリ)での絞り込み・難易度(★1〜★3)での絞り込み・キーワード検索
- 追加日から**2週間は自動で NEW バッジ**が付き、2週間たつと自動で消えます
- ヘッダーに「2週間以内の新着◯本」を自動表示
- ダークモード対応・スマホ/狭い画面対応

## コンテンツの追加・編集のしかた

`index.html` をテキストエディタで開き、`★ コンテンツはここを編集してください ★` と書いてあるすぐ下の `CONTENTS` を編集します。1件はこんな形です:

```js
{
  id: "kyomu-03",              // 他とかぶらない文字なら何でもOK
  category: "kyomu",           // kyomu / jugyo / blog(iportal) / note のどれか
  title: "動画のタイトル",
  description: "ひとこと説明",
  level: 1,                    // 難易度。1 / 2 / 3(星の数になります)
  duration: "8分",             // 記事なら "" でOK
  url: "https://…",            // 動画や記事のURL(Stream, YouTube, note など)
  formUrl: "https://forms.office.com/…", // 実践報告Forms(動画のみ。記事は "")
  date: "2026-07-14",          // 追加した日。ここから2週間 NEW が付きます
},
```

- 増やすときは、この `{ ... },` のかたまりをコピーして下に追記するだけです
- `url` や `formUrl` が空欄のあいだは、ボタンが「(準備中)」表示になります
- いまはサンプルのコンテンツが入っているので、実際のタイトルとURLに差し替えてください

## 公開のしかた(GitHub Pages)

1. このリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch でこのファイルがあるブランチと `/ (root)` を選んで Save
4. 数分すると `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

コンテンツを追加・編集してコミットすると、同じURLのまま数分で自動反映されます。

> ⚠️ GitHub Pages は誰でもアクセスできる公開ページです。ページに載るのはタイトルとリンクだけですが、リンク先(Stream・Forms・iportal)側が社内限定になっているかを確認してください。

## Teamsのタブに追加するしかた

1. Teamsのチャネル上部の **「+」(タブを追加)** をクリック
2. **「Webサイト」** を選ぶ
3. タブの名前(例: AIまなびば)と、公開したURLを貼り付けて保存

これでチャネルを開いたメンバー全員がタブから学習ページを見られます。

## 視聴の記録について

このページ自体は誰が見たかを記録しません。実践・視聴の把握は、動画とセットのMicrosoft Formsの回答で行う設計です。
