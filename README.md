# 🎋 七夕まつり 〜願いを夜空へ〜

好きな色の短冊に願い事を書いて笹に飾り、祈ると願いがキラキラと夜空へ昇っていく、七夕の体験アプリです。

## 遊び方

1. **色を選ぶ** — 五色(緑・赤・黄・白・水色)の短冊から好きな色を選びます
2. **願い事を書く** — 30文字までの願い事を入力します(縦書きで短冊に表示されます)
3. **笹に飾る** — 「飾る」ボタンで短冊が笹の枝先にふわりと掛かります
4. **祈る 🙏** — そっと目を閉じて祈ると、短冊がきらめき、光の粒が夜空へ広がって「願いの星」になります

短冊をタップすると願い事を確認したり、外したりできます。願い事はブラウザ(localStorage)に保存され、次に開いたときも笹に残っています。

## みんなで飾る(QRシェア)

左上のQRボタンを押すとQRコードが表示されます。QRを読み取った人(またはリンクを開いた人)は**同じ笹**に短冊を飾れます。誰かが飾った短冊は数秒でみんなの画面に現れ、誰かが祈ると「とおくで だれかが 祈っています…」と全員の夜空がきらめきます。

この機能には Firebase Realtime Database の設定が必要です:

1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作成(Analyticsは不要)
2. 「構築 > Realtime Database」でデータベースを作成
3. ルールを以下のように設定:
   ```json
   { "rules": { "rooms": { ".read": true, ".write": true } } }
   ```
4. データベースのURL(`https://xxxx-default-rtdb.firebaseio.com` など)を `index.html` 内の `const DB_URL=''` に設定

DB_URL が未設定でも、共有以外の機能はすべて動作します。

## 実行方法

ビルド不要・依存なしの単一 HTML ファイルです。

```
index.html をブラウザで開くだけ
```

スマートフォン・PC どちらでも動作します。
