# AIまなびば 🌸

ももいろ先生のAI活用学習ハブ。Microsoft Teamsのチャネル上部にタブとして置いて使うための、1ファイル完結のウェブサイトです。

## コンテンツの種類

| カテゴリ | 内容 | ボタン |
| --- | --- | --- |
| 教務×AI 動画 | 教務に使えるAI活用動画 | 動画を見る + 実践報告フォーム(Forms) |
| 授業×AI 動画 | 授業に使えるAI活用動画 | 動画を見る + 実践報告フォーム(Forms) |
| 社内ブログ | 社内ブログの記事 | 記事を読む |
| ももいろ先生のnote | note記事 | 記事を読む |

そのほかの機能:

- カテゴリ絞り込み・キーワード検索
- 「実践したらチェック」で進捗が保存され、カードに「済」スタンプが押されます(進捗リングも動きます)
- 追加から14日以内のコンテンツには NEW バッジが付きます
- ダークモード対応・スマホ/狭い画面対応

## コンテンツの追加・編集のしかた

`index.html` をテキストエディタで開き、`★ コンテンツはここを編集してください ★` と書いてあるすぐ下の `CONTENTS` を編集します。1件はこんな形です:

```js
{
  id: "kyomu-03",              // 他とかぶらない文字なら何でもOK。あとから変えない
  category: "kyomu",           // kyomu / jugyo / blog / note のどれか
  title: "動画のタイトル",
  description: "ひとこと説明",
  duration: "8分",             // 記事なら "" でOK
  url: "https://…",            // 動画や記事のURL(Stream, YouTube, note など)
  formUrl: "https://forms.office.com/…", // 実践報告Forms(動画のみ。記事は "")
  date: "2026-07-14",          // 追加した日
},
```

- 増やすときは、この `{ ... },` のかたまりをコピーして下に追記するだけです
- `url` や `formUrl` が空欄のあいだは、ボタンが「(準備中)」表示になります
- いまはサンプルのコンテンツが入っているので、実際のタイトルとURLに差し替えてください

## 公開のしかた(GitHub Pages)

1. このリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch でこのファイルがあるブランチと `/ (root)` を選んで Save
4. 数分すると `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

> ⚠️ GitHub Pages は誰でもアクセスできる公開ページです。ページに載るのはタイトルとリンクだけですが、リンク先(Stream・Forms・社内ブログ)側が社内限定になっているかを確認してください。社外に一切見せたくない場合は、SharePointのドキュメントライブラリ等での運用をご相談ください。

## Teamsのタブに追加するしかた

1. Teamsのチャネル上部の **「+」(タブを追加)** をクリック
2. **「Webサイト」** を選ぶ
3. タブの名前(例: AIまなびば)と、公開したURLを貼り付けて保存

これでチャネルを開いたメンバー全員がタブから学習ページを見られます。

## 進捗データについて

「実践したらチェック」の進捗は、各ユーザーのブラウザ(localStorage)にだけ保存されます。誰が何を見たかを集めたい場合は、動画とセットのMicrosoft Formsの回答で把握できます。
